How to use

  1. On the offline machine open sender.html in any browser and pick a file.
  2. On the phone open the receiver, tap Start camera and point it at the screen.
  3. Press Start on the sender. It shows every block once, then switches to repair codes.
  4. Each repair code can stand in for any one missed block — after about as many repair codes as blocks you missed, the receiver completes. Tap Save file.
  5. Alternatively copy the receiver's “Missed blocks” list into the sender's Resend only blocks field.

Tuning: watch Codes/s on the receiver. If nothing is being missed, lower the sender's frame time or show 2–4 codes per frame. If many are missed, slow down or use a stand. The receiver works offline once loaded; received data never leaves the device. sender-classic.html is the v1 sender for the original scanner.
